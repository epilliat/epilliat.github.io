Context

\(Y\) is a binary variable \(Y_k \in \{0,1\}\)

\(X = (X^{(1)}, \ldots, X^{(p)})\) are \(p\) regressors

\(Y|X = x\) follows a Bernoulli distribution with parameter \(p(x) = P(Y = 1|X = x)\). We model it as

\[p(x) = g^{-1}(x^T\beta)\]

where \(g^{-1}\) is a strictly increasing function with values in \([0, 1]\)

First question: how to choose \(g^{-1}\) (equivalently, the link function \(g\))?

Which Link Function for Binary Y?

Question: which link function should we choose in practice when \(Y\) is binary?

Default choice: we favor the logit model

Exceptions: unless there is a good reason to choose another link (probit, complementary log-log, or log-log)

Next steps: we revisit the 3 usual choices to justify this preference

Details on the Probit Model

The probit model is justified when the binary variable \(Y|X = x\) comes from thresholding a Gaussian latent variable \(Z(x)\):

\[(Y|X = x) = \mathbf{1}_{Z(x) \geq \tau}\]

where \(Z(x) \sim \mathcal{N}(x^T\beta, \sigma^2)\)

With \(\Phi\) the CDF of \(\mathcal N(0,1)\), we get \[P(Y = 1|X = x) = P(Z(x) \geq \tau) = \Phi\left(\frac{x^T\beta - \tau}{\sigma}\right)\]

Examples in Probit Model

  • \(Y\) is a purchase decision, and \(Z(x)\) quantifies the utility of the good
  • \(Y\) is a declared psychological state (happiness, depression) and \(Z(x)\) is an unobserved (latent) measure of personal satisfaction

Probit vs Logit: Current Trends

Econometricians: the probit model remains fairly popular among econometricians…

General trend: …but it tends to be replaced by the logistic model

Advantages of logit: the logit model has many advantages that probit lacks:

  • Interpretation of results
  • Explicit formulas

Theoretical justification: the probit CDF is close to the logit CDF

Remarks on cloglog Model

The model is \(p(x) = g^{-1}(x^T\beta)\) with

\[g(t) = \ln(-\ln(1-t)) \quad \text{i.e.} \quad g^{-1}(t) = 1 - e^{-e^t}\]

It is not symmetric, in the sense that \(g(t) \neq -g(1-t)\).

\(p(x)\) approaches \(0\) slowly but \(1\) very rapidly.

If the opposite holds (fast to \(0\), slow to \(1\)), take \(g(t) = -\ln(-\ln(t))\) (loglog model).

cloglog is useful in survival models (e.g. the Cox model).

Details on the Logit Model

  1. A highly valued interpretation tool: odds ratios.

  2. More convenient from a theoretical point of view.

  3. A natural model in many situations.

Theoretical Motivation of Logit

We will show in the exercises that:

If, in the two groups \(Y = 0\) and \(Y = 1\), \(X\) is Gaussian with different means \(m_0 \neq m_1\) (and the same covariance \(\Sigma\)),

\(X|(Y = 0) \sim \mathcal N(m_0, \Sigma) \and X|(Y = 1) \sim \mathcal N(m_1, \Sigma)\)

then \(\mathbb P(Y = 1|X = x)\) follows a logistic model.

The result still holds for two distributions of the same exponential family (with sufficient statistic \(x\)) that differ only by their natural parameter.

Summary for Binary Variables

If \(Y\) is a binary variable, \((Y|X = x) \sim \mathcal B(p(x))\).

In a GLM for \(Y\), we set \(p(x) = g^{-1}(x^T\beta)\) where \(g\) is:

  • by default the logit function, which is the most natural;

  • possibly probit if we have good reasons to justify it (but the results will be similar to logit);

  • cloglog (or loglog) if we have good reasons to justify it (strong asymmetry of \(p(x)\), connection with a Cox model).

From now on, we focus on the logit model.

Interpretation of the Logistic Model

For \(x=(x^{(1)}, \dots, x^{(p)}) \in \mathbb R^{p \times 1}\),

\[p(x) = \text{logit}^{-1}(x^T\beta) = \frac{e^{x^T\beta}}{1 + e^{x^T\beta}}\]

  • The map \(x^{(j)} \to p(x)\) (other regressors fixed) is increasing if \(\beta_j > 0\), decreasing if \(\beta_j < 0\) (constant if \(\beta_j = 0\)).

  • The larger \(|\beta_j|\), the stronger the discriminatory power of regressor \(X^{(j)}\): a small change in \(x^{(j)}\) can cause a large change in \(p(x)\).

Shape of the logistic curve

As a function of \(x^{(j)}\) (other regressors fixed): the sign of \(\beta_j\) gives the direction, \(|\beta_j|\) the steepness, slope \(\beta_j/4\) at \(p=1/2\).

βj 1.0   other terms 0.0

Odds

\[\text{odds} = \frac{p}{1-p}\]

Betting interpretation: odds of \(3\) to \(1\) mean that for every \(3\) people betting on \(A\), \(1\) person bets on \(B\).

So a randomly chosen bettor bets on \(A\) with probability \(p=3/4\) and on \(B\) with probability \(1-p=1/4\).

Odds given X=x

Similarly, the odds of \(Y = 1\) given \(X = x\) are

\[\text{odds}(x) = \frac{p(x)}{1 - p(x)}\]

where \(p(x) = P(Y = 1|X = x)\).

Odds Ratio

For two individuals with characteristics \(x_1\) and \(x_2\), the odds ratio between \(x_1\) and \(x_2\) is

\[OR(x_1, x_2) = \frac{\text{odds}(x_1)}{\text{odds}(x_2)} = \frac{\frac{p(x_1)}{1-p(x_1)}}{\frac{p(x_2)}{1-p(x_2)}}\]

Warning

DO NOT CONFUSE ODDS RATIO WITH PROBABILITY RATIO

Only possible exception: if \(p(x_1)\) and \(p(x_2)\) are both very small, then \(1 - p(x_1) \approx 1\) and \(1 - p(x_2) \approx 1\), so that \(OR(x_1, x_2) \approx p(x_1)/p(x_2)\)

Link with the Probability Ratio

However, the OR and the probability ratio are always on the same side of \(1\):

\[\begin{aligned} OR(x_1, x_2) > 1 &\Leftrightarrow \frac{p(x_1)}{p(x_2)} > 1\\ OR(x_1, x_2) < 1 &\Leftrightarrow \frac{p(x_1)}{p(x_2)} < 1\\ OR(x_1, x_2) = 1 &\Leftrightarrow \frac{p(x_1)}{p(x_2)} = 1 \end{aligned}\]

Another Property of the Odds Ratio

\(OR(x_1, x_2)\) accentuates the differences: it is further from \(1\) than \(p(x_1)/p(x_2)\):

\[\begin{aligned} OR(x_1, x_2) > \frac{p(x_1)}{p(x_2)} &\text{ when } OR(x_1, x_2) > 1\\ OR(x_1, x_2) < \frac{p(x_1)}{p(x_2)} &\text{ when } OR(x_1, x_2) < 1 \end{aligned}\]

Examples Using Odds Ratios

Logistic regression is most often used to compare the behavior of two individuals with respect to the variable of interest.

Examples:

  • probability of purchase depending on whether or not one has been the subject of a personalized promotion;
  • probability of a breakdown of a vehicle according to its age;
  • probability of recovery according to the treatment used.

Odds Ratio in Logistic Regression

In the logistic model, \(\text{odds}(x) = \frac{p(x)}{1 - p(x)} = \exp(x^T \beta)\)

Hence

\(OR(x_1, x_2) = \frac{\text{odds}(x_1)}{\text{odds}(x_2)} = \exp((x_1 - x_2)^T \beta)\)

If the two individuals differ only in regressor \(j\):

\(OR(x_1, x_2) = \exp(\beta_j (x_1^{(j)} - x_2^{(j)}))\)

If regressor \(j\) is binary (\(x_1^{(j)} = 1\) and \(x_2^{(j)} = 0\)):

\(OR(x_1, x_2) = \exp(\beta_j)\)

Key Summary Statement

In a logistic regression model, \(\beta_j\) is the logarithm of the odds ratio between two individuals whose regressor \(j\) differs by \(1\), all else being equal.

In brief: \(\exp(\beta_j) = OR(x^{(j)} + 1, x^{(j)})\)

If regressor \(j\) is binary (presence or absence of a characteristic):

\(\exp(\beta_j)\) is simply the OR between presence and absence of this characteristic, all else being equal.

Estimation of the Parameters

Outline: Estimation

  • Likelihood and log-likelihood of the logistic model
  • The MLE has no closed form: numerical optimization
  • Uniqueness (when \(\text{rank}(X) = p\)) and existence (when the classes overlap)
  • Asymptotic normality of \(\hat\beta\) and Fisher information

The Framework

We observe \(n\) i.i.d. realizations \((Y_i, X_i)\) where \(Y_i \in \{0, 1\}\) and \(X_i \in \mathbb{R}^p\).

We write \(p(x_i) = P(Y_i = 1|X_i = x_i)\).

The Logistic Model

We assume the logistic model: for all \(i\),

\[p(x_i) = \text{logit}^{-1}(x_i^T \beta) = \frac{e^{x_i^T \beta}}{1 + e^{x_i^T \beta}}\]

where \(\beta = (\beta_1, \ldots, \beta_p)^T\) and \(x_i^T \beta = \beta_1 x_i^{(1)} + \cdots + \beta_p x_i^{(p)}\).

Parameter Estimation

\[p(x_i) = \text{logit}^{-1}(x_i^T \beta) = \frac{e^{x_i^T \beta}}{1 + e^{x_i^T \beta}}\]

We will estimate \(\beta\) by maximizing the likelihood.

We write \(p_\beta(x_i)\) instead of \(p(x_i)\) to emphasize its dependence on \(\beta\).

Likelihood Calculation

For each \(i\), \(Y_i|(X_i = x_i)\) follows the Bernoulli distribution \(B(p_\beta(x_i))\), so

\[P(Y_i = y_i|X_i = x_i) = p_\beta(x_i)^{y_i}(1 - p_\beta(x_i))^{1-y_i}\]

for all \(y_i \in \{0, 1\}\).

Likelihood

By independence, we obtain the likelihood

\[\ell(\beta, y_1, \ldots, y_n, x_1, \ldots, x_n) = \prod_{i=1}^n p_\beta(x_i)^{y_i}(1 - p_\beta(x_i))^{1-y_i}\]

Log-Likelihood

Taking the log and plugging in the expression of \(p(x_i)\), we get the log-likelihood:

\[\begin{aligned} L(\beta, y_1, \ldots, y_n, x_1, \ldots, x_n) &= \ln(\ell) \\ &=\sum_{i=1}^n \left[y_i x_i^T \beta - \ln(1 + e^{x_i^T \beta})\right] \end{aligned}\]

MLE Calculation

If it exists, the MLE \(\hat{\beta}\) is a zero of the gradient of \(L\) with respect to \(\beta\), which equals

\[\frac{\partial L}{\partial \beta} = \sum_{i=1}^n x_i \left(y_i - \frac{e^{x_i^T \beta}}{1 + e^{x_i^T \beta}}\right)\]

We must therefore solve a system of \(p\) equations in \(p\) unknowns.

There is no explicit solution: we use numerical methods (Newton–Raphson algorithm).

Remarks on Optimization

This is typical of advanced statistical models: we often rely on optimization algorithms.

Two questions: does the solution exist? Is it unique?

MLE Uniqueness

Let \(X\) be the design matrix \((X^{(1)}, \dots, X^{(p)}) \in \mathbb R^{n \times p}\)

Proposition

If \(\text{rank}(X) = p\), then the MLE, if it exists, is unique.

Proof of MLE Uniqueness

It suffices to show that \(L\) is strictly concave in \(\beta\).

The Hessian matrix of \(L\) is

\[\frac{\partial^2 L}{\partial \beta^2} = -\sum_{i=1}^n p_\beta(x_i)(1 - p_\beta(x_i)) x_i x_i^T\]

Hessian Properties

It is negative semi-definite. Moreover, for every \(u \in \mathbb{R}^p\),

\[\begin{aligned} u^T \frac{\partial^2 L}{\partial \beta^2} u = 0 &\Leftrightarrow u^T x_i x_i^T u = 0 \text{ for all } i\\ &\Leftrightarrow u^T x_i = 0 \text{ for all } i\\ &\Leftrightarrow Xu = 0\\ &\Leftrightarrow u = 0 \end{aligned}\]

where the last equivalence holds since \(\text{rank}(X) = p\).

Conclusion

Hence, for every \(u \neq 0\),

\[u^T \frac{\partial^2 L}{\partial \beta^2} u < 0\]

The Hessian is negative definite, so \(L\) is strictly concave.

Hence the MLE, if it exists, is unique.

About MLE Existence

Even though \(L\) is strictly concave, its maximum can occur at infinity (think of \(t \mapsto -\ln(1+e^{-t})\), which increases towards \(0\) without ever reaching it); then \(\hat{\beta}\) does not exist.

This happens when there is non-overlap, i.e. when a hyperplane separates the \(x_i\) with \(y_i = 0\) from those with \(y_i = 1\).

Non-Overlap Situation

Mathematically, there is non-overlap if there exists \(\alpha \in \mathbb{R}^p\), \(\alpha \neq 0\), such that

\[\begin{cases} \text{for all } i \text{ such that } y_i = 0, & \alpha^T x_i \geq 0 \\ \text{for all } i \text{ such that } y_i = 1, & \alpha^T x_i \leq 0 \end{cases}\]

Non-Overlap and Existence

Proposition (admitted)

In case of non-overlap, \(\hat{\beta}\) does not exist: \(L(\beta)\) is maximal only as \(\|\beta\| \to \infty\) (in one or several directions).

As \(\|\beta\| \to \infty\) along a separating direction, \(p_\beta(x) \to 0\) or \(1\) for every \(x\) off the hyperplane, depending on its side.

However, there is a “dead zone” between the \(2\) point clouds, because the separating hyperplane is not necessarily unique.

Beyond the Dead Zone

Outside this dead zone, classification is trivial (\(0\) or \(1\)).

But the model cannot be interpreted: the ORs are \(0\) or \(+\infty\).

Existence and Uniqueness of MLE

We say that there is overlap when no hyperplane separates the red points from the blue points (the \(x_i\) with \(y_i = 0\) from those with \(y_i = 1\)).

Proposition (admitted)

If \(\text{rank}(X) = p\) and there is overlap, then the MLE exists and is unique.

Under these conditions, we can safely search for the MLE with the Newton–Raphson algorithm, since:

  1. the maximum exists,

  2. the function to optimize is strictly concave, so it has no local maximum other than the global one.

Fisher Information (Recall)

Let \(X\) be the design matrix (whose rows are the vectors \(x_i\)).

We denote by \(J_n(\beta)\) the Fisher information matrix:

\[J_n(\beta) = -E\left[\frac{\partial^2 L}{\partial \beta^2}(\beta) \bigg| X\right]\]

Asymptotic Normality of the MLE

Proposition (admitted)

In the logistic regression model, if

  1. the distribution of the regressors \((X^{(1)}, \ldots, X^{(p)})\) has compact support,
  2. \(\text{rank}(X) = p\),
  3. the smallest eigenvalue of \(X^T X\) tends to infinity with \(n\),

then

  1. the maximum likelihood estimator \(\hat{\beta}\) is consistent;

  2. \(J_n(\beta)^{1/2}(\hat{\beta} - \beta) \xrightarrow{L} N(0, I_p)\)

where \(I_p\) is the identity matrix of size \(p\).

Comments

Under these conditions, the MLE exists for \(n\) large enough: the probability of overlap tends to \(1\) as \(n \to \infty\).

The MLE is asymptotically efficient (minimal asymptotic variance).

We can rely on asymptotic normality to build tests and confidence intervals.

Comparison: Linear Regression

The formula for \(\hat{\beta}\) is explicit: \(\hat{\beta} = (X^T X)^{-1} X^T Y\);

Its expectation and variance are explicit;

In the Gaussian model (\(Y|X\) Gaussian), the distribution of \(\hat{\beta}\) is explicit, which gives exact tests (Student, Fisher).

Without the Gaussian assumption, these tests are only asymptotically valid.

Comparison: Logistic Regression

No explicit formula for \(\hat{\beta}\): it is computed numerically;

We know neither the bias nor the variance of \(\hat{\beta}\);

The distribution of \(Y|X\) is simple (a Bernoulli), but the exact distribution of \(\hat{\beta}\) is unknown.

We only know its asymptotic distribution.

Hence we use asymptotic tests!

Wald Tests and Confidence Intervals

Outline: Inference

  • Wald tests and confidence intervals, from the asymptotic normality of \(\hat\beta\): one coefficient, one odds ratio
  • Deviance: how far a model is from the saturated model
  • Deviance tests (likelihood ratio tests) for nested models; AIC and BIC

Asymptotic Framework

Under “good conditions” (see the proposition above),

\[J_n(\beta)^{1/2}(\hat{\beta} - \beta) \xrightarrow{L} N(0, I_p)\]

where \(J_n(\beta)\) is the Fisher information matrix.

To build asymptotic tests, we need an expression for \(J_n(\beta)\) and a way to estimate it (\(\beta\) is unknown).

Computation of Jₙ(β)

\[J_n(\beta) = -E\left[\frac{\partial^2 L}{\partial \beta^2}(\beta) \bigg| X\right]\]

where \(L\) is the log-likelihood of the model.

Using the Hessian computed in the uniqueness proof,

\[J_n(\beta) = \sum_{i=1}^n p_\beta(x_i)(1 - p_\beta(x_i)) x_i x_i^T\]

Equivalent Form

Equivalently,

\[J_n(\beta) = X^T W_\beta X\]

where \(X\) is the design matrix and \(W_\beta\) is the diagonal matrix

\[W_\beta = \begin{pmatrix} p_\beta(x_1)(1 - p_\beta(x_1)) & 0 & \cdots & 0 \\ 0 & p_\beta(x_2)(1 - p_\beta(x_2)) & \cdots & 0 \\ \vdots & \vdots & \ddots & \vdots \\ 0 & 0 & \cdots & p_\beta(x_n)(1 - p_\beta(x_n)) \end{pmatrix}\]

Estimating the Information Matrix

To estimate \(J_n(\beta)\), we simply replace \(\beta\) by the MLE \(\hat{\beta}\).

Under the same regularity assumptions, we can show that

\[J_n(\hat{\beta})^{1/2}(\hat{\beta} - \beta) \xrightarrow{L} N(0, I_p)\]

Estimated Variance of β̂ⱼ

\[J_n(\hat{\beta})^{1/2}(\hat{\beta} - \beta) \xrightarrow{L} N(0, I_p)\]

Denote by \(\hat{\sigma}_j^2\) the \(j\)-th diagonal element of \(J_n(\hat{\beta})^{-1}\). Then (admitted):

\[\frac{\hat{\beta}_j - \beta_j}{\hat{\sigma}_j} \xrightarrow{L} N(0, 1)\]

Confidence Interval

This yields a confidence interval for \(\beta_j\) at asymptotic confidence level \(1 - \alpha\):

\[\text{CI}_{1-\alpha}(\beta_j) = \left[\hat{\beta}_j - q_{1-\alpha/2}\hat{\sigma}_j \,;\, \hat{\beta}_j + q_{1-\alpha/2}\hat{\sigma}_j\right]\]

where \(q_{1-\alpha/2}\) is the quantile of order \(1 - \alpha/2\) of the \(N(0, 1)\) distribution.

One can check that \(\P(\beta_j \in \text{CI}_{1-\alpha}(\beta_j)) \to 1 - \alpha\).

Significance Test for One Coefficient

We want to test \(H_0: \beta_j = 0\) against \(H_1: \beta_j \neq 0\).

Under \(H_0\), \(\frac{\hat{\beta}_j}{\hat{\sigma}_j} \xrightarrow{L} N(0, 1)\)

This gives a critical region at asymptotic level \(\alpha\):

\[\mathcal R_\alpha = \left\{\frac{|\hat{\beta}_j|}{\hat{\sigma}_j} > q_{1-\alpha/2}\right\}\]

Indeed \(P_{H_0}(\mathcal R_\alpha) \to \alpha\).

This is the Wald test (based on the asymptotic normality of the MLE).

P-value

With \(\Phi\) the cdf of the \(\mathcal N(0, 1)\) distribution, the p-value of the test is

\[p\text{-value} = 2\left(1 - \Phi\left(\frac{|\hat{\beta}_j|}{\hat{\sigma}_j}\right)\right)\]

Estimation of an Odds-Ratio

Consider two individuals \(1\) and \(2\) who differ only in regressor \(j\). Then

\[OR(x_1^{(j)}, x_2^{(j)}) = e^{\beta_j(x_1^{(j)} - x_2^{(j)})}\]

Question: do we have \(OR(x_1^{(j)}, x_2^{(j)})\approx 1\)?

The OR is simply estimated by

\[\widehat{OR}(x_1^{(j)}, x_2^{(j)}) = e^{\hat{\beta}_j(x_1^{(j)} - x_2^{(j)})}\]

Important Example

If regressor \(j\) is binary with \(x_1^{(j)} = 1\) and \(x_2^{(j)} = 0\), then

\[\widehat{OR}(x_1^{(j)}, x_2^{(j)}) = e^{\hat{\beta}_j}\]

Asymptotic CI for an Odds-Ratio

We have seen that an asymptotic CI at confidence level \(1 - \alpha\) for \({\beta}_j\) is

\[\text{CI}_{1-\alpha}(\beta_j) = \left[\hat{\beta}_j - q_{1-\alpha/2}\hat{\sigma}_j \,;\, \hat{\beta}_j + q_{1-\alpha/2}\hat{\sigma}_j\right]= [l,r]\]

If \(x_1^{(j)} > x_2^{(j)}\), an asymptotic CI for \(OR(x_1^{(j)}, x_2^{(j)})= e^{\beta_j(x^{(j)}_1 - x^{(j)}_2)}\) at level \(1 - \alpha\) is

\[\text{CI}_{1-\alpha}(OR(x_1^{(j)}, x_2^{(j)})) = \left[e^{l(x_1^{(j)} - x_2^{(j)})}, e^{r(x_1^{(j)} - x_2^{(j)})}\right]\]

Significance Test for an Odds-Ratio

We usually want to compare \(OR(x_1^{(j)}, x_2^{(j)})\) with \(1\):

\[OR(x_1^{(j)}, x_2^{(j)}) = 1 \Leftrightarrow e^{\beta_j(x_1^{(j)} - x_2^{(j)})} = 1 \Leftrightarrow \beta_j = 0\]

Two-Sided Test

\(H_0: OR(x_1^{(j)}, x_2^{(j)}) = 1\) VS \(H_1: OR(x_1^{(j)}, x_2^{(j)}) \neq 1\)

amounts to testing \(H_0: \beta_j = 0\) against \(H_1: \beta_j \neq 0\). The rejection region at asymptotic level \(\alpha\) is

\[\mathcal R_\alpha = \left\{\frac{|\hat{\beta}_j|}{\hat{\sigma}_j} > q_{1-\alpha/2}\right\}\]

One-Sided Tests

However, for ORs, one often prefers one-sided tests, e.g.

\(H_0: OR(x_1^{(j)}, x_2^{(j)}) = 1\) VS \(H_1: OR(x_1^{(j)}, x_2^{(j)}) > 1\)

If \(x_1^{(j)} > x_2^{(j)}\), then \(OR(x_1^{(j)}, x_2^{(j)}) \geq 1 \Leftrightarrow \beta_j \geq 0\), so the rejection region at asymptotic level \(\alpha\) is

\[\mathcal R_{\alpha}=\left\{\frac{\hat{\beta}_j}{\hat{\sigma}_j} > q_{1-\alpha}\right\}\]

Deviance

Saturated Model

Suppose we have \(n\) observations \((Y_1, \dots, Y_n)\) and \((X_1, \dots, X_n)\), with categorical regressors.

Here \(X_k\) may be a vector \(X_k = (X^{(1)}_k, \dots, X^{(p)}_k)^T\).

Assume that the individuals are i.i.d., with \(\mathbb P(Y=1|X_k=x) = p(x)\).

How do we estimate \(p(x)\)?

Saturated Estimator

Suppose we have \(n\) observations \((Y_1, \dots, Y_n)\) and \((X_1, \dots, X_n)\)

\(n(x) = |\{k:~ X_k = x\}|\) (number of individuals \(k\) with \(X_k=x\))

\(n_1(x) = |\{k:~ X_k = x ~~\text{and}~~Y_k=1\}|\)

The saturated model estimates \(p(x)\), for each observed \(x\), by

\[\hat{p}_{\text{sat}}(x) = \frac{n_1(x)}{n(x)}\]

Saturated Estimator: Illustration

Few distinct values of \(x\): \(\hat p_{\text{sat}}(x)=n_1(x)/n(x)\) is close to \(p(x)\). All values distinct: it is \(0\) or \(1\). The nearest neighbour rule extends it to every \(x\).

distinct values of x:  

Remark: Distinct Observations

\[\hat{p}_{\text{sat}}(x) = \frac{n_1(x)}{n(x)}\]

If all observations are distinct, i.e. each observed \(x\) corresponds to a single individual, then for every observed \(x\):

\(n(x) = 1\), \(n_1(x) \in \{0,1\}\), and \(\hat{p}_{\text{sat}}(x) = 0\) or \(1\).

Properties of the Saturated Model

The saturated model is the most flexible model: one parameter per distinct value of \(x\).

It fits the data perfectly.

However, it has no explanatory power (what is the effect of the regressors on \(Y\)?).

Nor does it say anything about \(p(x)\) for an unobserved \(x\).

It serves as a reference to assess the fit of other models.

Likelihood of Saturated Estimator

Given probabilities \(p(x)\), the log-likelihood is

\[L(y_1, \ldots, y_n|x_1, \ldots, x_n) = \sum_{i=1}^n y_i \ln(p(x_i)) + (1 - y_i) \ln(1 - p(x_i))\]

The saturated estimator maximizes this log-likelihood over all choices of \(p(x)\); we denote

\[L_{\text{sat}} = \sum_{i=1}^n y_i \ln(\hat p_{\text{sat}}(x_i)) + (1 - y_i) \ln(1 - \hat p_{\text{sat}}(x_i))\]

Case 1: Distinct Observations

If all observations \(x_i\) are distinct, we have \(\hat{p}_{\text{sat}}(x_i) = y_i\) with \(y_i \in \{0, 1\}\), hence

\[L_{\text{sat}} = 0\]

This is the highest possible log-likelihood: the saturated estimator fits the data perfectly (too well).

Case 2: Non-Distinct Observations

If the observations \(x_i\) are not distinct, we obtain

\[L_{\text{sat}} = \sum_x \left[n_1(x) \ln\left(\frac{n_1(x)}{n(x)}\right) + (n(x) - n_1(x)) \ln\left(1 - \frac{n_1(x)}{n(x)}\right)\right]\]

where the sum runs over the distinct values \(x\) taken by the \(x_i\).

Deviance

The deviance of a model measures how much it deviates from the saturated model (the best possible model in terms of likelihood).

\[D = 2(L_{\text{sat}} - L_{\text{mod}})\]

where \(L_{\text{mod}}\) is the maximized log-likelihood of the model.

We always have \(D \geq 0\).

If all observations are distinct, \(L_{\text{sat}} = 0\), hence \(D = -2L_{\text{mod}}\)

Role of Deviance and Computation in R

\[D = 2(L_{\text{sat}} - L_{\text{mod}})\]

Deviance plays the role of the SSR of a linear model: the higher the deviance, the worse the model fits the data.

With 0/1 responses (one row per individual), R takes \(L_{\text{sat}} = 0\): the reported deviance is \(-2L_{\text{mod}}\).

Deviance Tests and Model Selection

Linear Constraint Test

As in linear regression, we want to test \(H_0: R\beta = 0\) VS \(H_1: R\beta \neq 0\)

where \(R\) is a full-rank constraint matrix of size \((q, p)\).

Recall that, depending on the choice of \(R\), this covers:

  • the global test: is there at least one relevant regressor?

  • comparing nested models

  • the joint significance of a group of regressors

Available Procedures

In GLMs, three test procedures address this problem.

The Wald test, based on the asymptotic normality of \(\hat{\beta}\), generalizing the test of \(\beta_j = 0\) against \(\beta_j \neq 0\) seen earlier.

The likelihood ratio test, called in this context the deviance test.

The score test, based on the gradient of the log-likelihood at the MLE under \(H_0\), \(\hat{\beta}_{H_0}\).

Most used: the deviance test.

The Deviance Test (or Likelihood Ratio Test)

To test \(H_0: R\beta = 0\) against \(H_1: R\beta \neq 0\), the principle is as follows.

Compute the MLE in each model: \(\hat{\beta}\) in the full model and \(\hat{\beta}_{H_0}\) in the constrained model.

Logic: If \(H_0\) is true, the constrained model should be as “likely” as the full model, so \(L(\hat{\beta})\) and \(L(\hat{\beta}_{H_0})\) should be similar.

Deviance Test Statistic

The test statistic is the difference of deviances:

\[D_{H_0} - D_{H_1} = 2\left(L(\hat{\beta}) - L(\hat{\beta}_{H_0})\right)\]

Under \(H_0\), with \(q\) the number of constraints, we have (admitted):

\[D_{H_0} - D_{H_1} = 2\left(L(\hat{\beta}) - L(\hat{\beta}_{H_0})\right) \xrightarrow{L} \chi^2_q\]

Rejection Region and P-value

The rejection region at asymptotic level \(\alpha\) is therefore

\[\mathcal R_\alpha = \{D_{H_0} - D_{H_1} > \chi^2_{q,1-\alpha}\}\]

where \(\chi^2_{q,1-\alpha}\) is the quantile of order \(1 - \alpha\) of the \(\chi^2_q\) distribution.

The p-value is

\[p\text{-value} = 1 - F(D_{H_0} - D_{H_1})\]

where \(F\) is the cdf of a \(\chi^2_q\) distribution.

Special Case 1: Significance Test

We want to test whether a model (with a constant) is significant.

We test \(H_0\): all coefficients are zero except the constant, i.e. the special case

\(R = [0 | I_{p-1}]\).

We compare the deviance of the model to the null deviance \(D_0\), the deviance of the model containing only the constant.

Test Statistic

The test statistic is \(D_0 - D\). Under \(H_0\), when \(n \to \infty\):

\[D_0 - D \sim \chi^2_{p-1}\]

The model is declared significant (relative to the null model) if the sample falls in the critical region of asymptotic level \(\alpha\):

\[\mathcal R_\alpha = \{D_0 - D > \chi^2_{p-1,1-\alpha}\}\]

Special Case 2: Nested Models

Suppose that model \(1\) (with deviance \(D_1\)) is a sub-model of model \(2\) (with deviance \(D_2\))

Model \(1\) is then obtained from model \(2\) (parameter \(\beta\)) through a constraint \(R\beta = 0\), where \(R\) is a \((q, p)\) matrix.

Under \(H_0: R\beta = 0\), we have asymptotically \(D_1 - D_2 \sim \chi^2_q\)

Hence the asymptotic test:

\(\mathcal R_\alpha = \{D_1 - D_2 > \chi^2_{q,1 - \alpha}\}\)

AIC and BIC Criteria

AIC and BIC are defined as in linear regression:

\(\text{AIC} = -2L_{\text{mod}} + 2p\)

\(\text{BIC} = -2L_{\text{mod}} + \ln(n)p\)

where \(L_{\text{mod}}\) is the maximized log-likelihood of the fitted model.

AIC and BIC via Deviance

If we ignore the saturated likelihood, i.e. set \(L_{\text{sat}}=0\),

\(\text{AIC} = D + 2p\)

\(\text{BIC} = D + \ln(n)p\)

In practice, we choose the model with the smallest AIC or BIC.

As in linear regression, we can use automatic selection procedures (backward, forward, etc.).

Example: Obesity Study

model=glm(Y~AGE+DBP+SEXE+ACTIV+WALK+MARITAL, family=binomial)
summary(model)
Statistic Value Degrees of Freedom
Null deviance \(4610.8\) on \(5300\)
Residual deviance \(4459.5\) on \(5290\)
AIC \(4481.5\)

The model deviance is \(D = 4459.5\).

Significance test: we compare \(D\) to the null deviance \(D_0 = 4610.8\): \(D_0 - D = 151.3\). The p-value of the test is \(1 - F_{10}(151.3) \approx 0\) where \(F_{10}\) is the cdf of a \(\chi^2_{10}\).

The model is significant.

Example: Significance Test of MARITAL

model=glm(Y~AGE+DBP+SEXE+ACTIV+WALK, family=binomial) # We want to test if `MARITAL` is significant
summary(model)
Statistic Value Degrees of Freedom
Null deviance \(4610.8\) on \(5300\)
Residual deviance \(4462.7\) on \(5295\)
AIC \(4474.7\)

The deviance is now \(D_2 = 4462.7\). Compared with the previous model: \(D_2 - D = 3.2\).

The p-value of the test is \(1 - F_5(3.2) \approx 0.67\), where \(F_5\) is the cdf of the \(\chi^2_5\) distribution.

We therefore do not reject \(H_0\): the MARITAL coefficients can be taken to be zero (the AIC confirms it).

Example: Significance Test of AGE²

model=glm(Y~AGE+I(AGE^2)+DBP+SEXE+WALK+ACTIV, family=binomial) # We add AGE^2
summary(model)
Statistic Value Degrees of Freedom
Null deviance \(4610.8\) on \(5300\)
Residual deviance \(4439.5\) on \(5294\)
AIC \(4453.5\)

The deviance test against the previous model has p-value \(1 - F_1(4462.7 - 4439.5) = 1 - F_1(23.2) \approx 10^{-6}\)

This model is therefore preferable (the AIC confirms it).

However, we cannot compare this model with the first one by a deviance test, since they are not nested.

We can still compare their AICs: this model is preferable.

Prediction

Setting and Objective

Suppose we are interested in a new individual for whom

  • we know their characteristics \(x \in \mathbb{R}^p\),
  • we do not know their \(Y\).

Goal: predict \(Y\) for this new individual.

Recall in the Logit Model

Once we have fitted a logistic regression model, we estimate

\[p_\beta(x) = P(Y = 1|X = x)\]

by

\[p_{\hat{\beta}}(x) = \text{logit}^{-1}(x^T \hat{\beta}) = \frac{e^{x^T \hat{\beta}}}{1 + e^{x^T \hat{\beta}}}\]

Outline for Prediction

\[p_\beta(x) = P(Y = 1|X = x)\]

We will see:

  1. how to construct a confidence interval around the estimate \(p_{\hat{\beta}}(x)\);

  2. how to use this estimate to classify the new individual in category \(Y = 0\) or \(Y = 1\).

CI: Asymptotic Distribution of β̂

We know that, for large \(n\) (when \(n \to \infty\)):

\[\hat{\beta} \sim N(\beta, (X^T W_{\hat{\beta}} X)^{-1})\]

  • \(X=(X^{(1)}, \dots, X^{(p)})\) is the \(n \times p\) design matrix
  • \(W_{\hat{\beta}}\) is the \(n \times n\) diagonal matrix with diagonal entries \(p_{\hat \beta}(x_i)(1-p_{\hat \beta}(x_i))\)

CI for Linear Predictor

Hence, when \(n \to +\infty\), \(x^T \hat{\beta} \sim N(x^T \beta, x^T (X^T W_{\hat{\beta}} X)^{-1} x)\), which gives the asymptotic CI for \(x^T\beta\):

\[\text{CI}_{1-\alpha}(x^T \beta) = \left[x^T \hat{\beta} \pm q_{1-\alpha/2} \sqrt{x^T (X^T W_{\hat{\beta}} X)^{-1} x}\right]\]

CI for Probability pβ(x)

Since \(p_{\hat{\beta}}(x) = \text{logit}^{-1}(x^T \hat{\beta})\) and \(\text{logit}^{-1}\) is increasing, applying it to both bounds gives the CI at asymptotic level \(1 - \alpha\):

\[\text{CI}_{1-\alpha}(p_\beta(x)) = \left[\text{logit}^{-1}\left(x^T \hat{\beta} \pm q_{1-\alpha/2} \sqrt{x^T (X^T W_{\hat{\beta}} X)^{-1} x}\right)\right]\]

Classification

We have estimated \(p_\beta(x) = P(Y = 1|X = x)\) by \(p_{\hat{\beta}}(x)\).

For a threshold \(s \in [0, 1]\) to be chosen, we use the rule:

\[\begin{cases} \text{if } p_{\hat{\beta}}(x) > s, & \hat{Y} = 1 \\ \text{if } p_{\hat{\beta}}(x) \leq s, & \hat{Y} = 0 \end{cases}\]

The “natural” choice of threshold is \(s = 0.5\) but this choice can be optimized.

Confusion Matrix

We use a validation sample:

Fit the model on a train sample, predict \(Y\) on a test sample, and form the confusion matrix.

\(Y = 0\) \(Y = 1\)
\(\hat{Y} = 0\) TN FN
\(\hat{Y} = 1\) FP TP

Reading: T = true, F = false, N = negative, P = positive.

FP (false positives): number of individuals classified positive who are actually negative.

Sensitivity and Specificity

Ideally, the confusion matrix is as diagonal as possible.

We generally seek to maximize the following indicators:

The sensitivity (or recall, or true positive rate) estimates \(\P(\hat{Y} = 1|Y = 1)\) by

\[\frac{\text{TP}}{\text{TP} + \text{FN}}\]

The specificity (or selectivity, or true negative rate) estimates \(\P(\hat{Y} = 0|Y = 0)\) by

\[\frac{\text{TN}}{\text{TN} + \text{FP}}\]

Other Indicators

The precision (or positive predictive value) estimates \(\P(Y = 1|\hat{Y} = 1)\) by

\(\frac{\text{TP}}{\text{TP} + \text{FP}}\)

The \(F\)-score is the harmonic mean of sensitivity and precision:

\[F_1 = 2 \frac{\text{precision} \times \text{sensitivity}}{\text{precision} + \text{sensitivity}}\]

Choice of Threshold s

For each threshold \(s\), using a test sample, we:

  • form the confusion matrix,
  • compute scores (sensitivity, \(F\)-score, etc.).

Finally, we choose the optimal threshold \(s\) for the chosen score.

Choosing the Score

  • It depends on the context of the study.
  • Wrongly predicting \(\hat{Y} = 0\) can be much more serious than wrongly predicting \(\hat{Y} = 1\):

False positive: \(\hat Y=1\) (treatment) while the patient is not ill (\(Y = 0\))

False negative: \(\hat Y=0\) (no treatment) while the patient has a serious illness (\(Y=1\))

ROC Curve

We can also plot the ROC curve (TP rate as a function of FP rate for \(s \in [0, 1]\)):

\(ROC:~~\mathrm{sensitiv.} = \frac{TP}{TP+FN} = F\left(\frac{FP}{FP+TN}\right) = F(1-\mathrm{specific.})\)

The AUC (area under the curve) is a quality indicator of the model (\(0 \leq \text{AUC} \leq 1\)).

Equivalently, one can use the Gini index: \(2 \times \text{AUC} - 1\).

Use: compare \(2\) models by plotting the 2 ROC curves.
