Values

Variables & types

Assign with =, no declaration.

x = 3            # Int64
y = 2.5          # Float64
name = "Ada"     # String

typeof(x) = Python’s type(x).

Types matter a lot from the compilation module on.

Numbers

10 / 4      # 2.5  (true division)
10 ÷ 4      # 2    (Python's //)
10 % 4      # 2
2^10        # 1024
sqrt(2)     # 1.414…
  • Power is ^. Bet first: what does 2**10 do?
  • How do you type ÷? Next slide.

Unicode: \name then TAB

α = 0.1              # \alpha

2 ∈ [1, 2, 3]        # \in
2π                   # 2 * π

2α is 2 * α: formulas map straight to code.

Ranges, comprehensions, matrices

1:5                             # 1, 2, 3, 4, 5
1:2:9                           # 1, 3, 5, 7, 9
[i^2 for i in 1:5]              # [1, 4, 9, 16, 25]
[i for i in 1:10 if iseven(i)]  # [2, 4, 6, 8, 10]
M = [1 2 3; 4 5 6]              # 2×3 matrix
M[2, 3]                         # 6
  • Ranges are lazy; collect(1:2:9) builds the array.
  • Matrices are column-major (opposite of NumPy).

In a matrix literal, spaces separate columns, ; starts a new row. Column-major matters in the memory module.

Tuples, named tuples, dicts

t = (1, "two", 3.0)
p, q, s = t                  # q == "two"
t[1]                         # 1

nt = (x = 10, y = 20)
nt.x                         # 10

d = Dict("apple" => 3, "pear" => 5)
d["apple"]                   # 3
haskey(d, "pear")            # "pear" in d

Control flow

Blocks close with end

No :, no indentation rule.

for i in 1:3
    println(i)
end            # ← closes the loop
  • for, while, if, function, struct: each closed by end.
  • Indentation: for readers only.

Conditionals

x = 11
if x ≥ 16
    "excellent"
elseif x ≥ 10
    "pass"
else
    "fail"
end                    # "pass"

x ≥ 0 ? "pos" : "neg"  # ternary

elseif, one word. c ? a : b = Python’s a if c else b.

Loops

words = ["a", "b"]
for (i, w) in enumerate(words)
    println(i, " ", w)
end

[(i, w) for (i, w) in enumerate(words)]  # [(1, "a"), (2, "b")]
  • for … end, comprehensions: as in Python.
  • enumerate counts from 1.

let … end: a local scope

v = [10, 20, 30, 40, 50]
let
    acc = zero(eltype(v))      # 0 of v's type
    for i in eachindex(v)      # 1:5
        acc += v[i]
    end
    acc                        # → 150
end

Like a function body run at once. Later scripts time code inside let.

zero(eltype(v)) and eachindex(v) work for any array: later modules use them. The last expression is the block’s value.

Functions & types

Functions — three forms

function area_rect(L, w)      # 1) long
    return L * w
end

square(x) = x^2               # 2) one-line
cube = x -> x^3               # 3) lambda

greet(who; punct = "!") = "Hi $who$punct"   # kwarg after ;
greet("Bob"; punct = "?")                    # "Hi Bob?"
  • return optional: last expression is returned.
  • Trailing ! (push!, sort!): modifies its argument (convention).

Broadcasting: the dot .

xs = [1.0, 4.0, 9.0]
sqrt.(xs)       # [1.0, 2.0, 3.0]
xs .+ 1         # [2.0, 5.0, 10.0]
@. xs^2 + 1     # dot on EVERY op
  • Bet first: sqrt(xs), without the dot?
  • Works on your functions: square.(xs).
  • Chained dots fuse into one loop.

▶ Script: cell “Broadcasting” — try sqrt(xs).

sqrt(xs) is a MethodError: sqrt takes a number. The dot says “element by element”. Fusion: no temporary arrays.

Structs, not classes

struct Point            # immutable
    x::Float64
    y::Float64
end

mutable struct Counter; n::Int; end

pt = Point(1.0, 2.0)    # no __init__
c = Counter(0); c.n += 1  # fine
# pt.x = 5.0            # ERROR

Monte-Carlo π

Monte-Carlo π — the running example

function count_in_disk(n)
    hits = 0
    for _ in 1:n
        x, y = rand(), rand()
        if x^2 + y^2 ≤ 1
            hits += 1
        end
    end
    return hits
end
n = 100_000
4 * count_in_disk(n) / n       # ≈ 3.14

Back in every module: timed, then threads, then GPU. ▶ Script: cell “5. Monte-Carlo π”.

Fraction of random points of the unit square inside the quarter-disk → π/4.
