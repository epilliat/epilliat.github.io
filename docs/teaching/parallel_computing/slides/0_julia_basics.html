Monte-Carlo π

Uniform points in the unit square: the fraction with \(x^2+y^2\leq1\) estimates \(\pi/4\).

15-minute introduction. Julia is used for demonstrations; Python is the common exercise track. Students only need to read the Julia code. Two minutes here: increase n, then request a new sample. The filled points are inside the quarter disk; the hollow points are outside. The animation shows the count and 4 × hits/n. The seeded generator is for illustration, not a scientific RNG demonstration. Next: 3 minutes on the complete loop, 3 on syntax, 3 on the two additional tools, 4 on the reference table and a return to the loop. The remaining slides are optional reference.

One loop throughout the course

function count_in_disk(n)
    hits = 0
    for _ in 1:n
        x, y = rand(), rand()
        if x^2 + y^2 ≤ 1
            hits += 1
        end
    end
    return hits
end
4 * count_in_disk(100_000) / 100_000       # ≈ 3.14

What does this function return? Which syntax differs from Python?

Reading the loop

for _ in 1:n                 # repeat n times
    x, y = rand(), rand()    # sample a uniform point
    if x^2 + y^2 ≤ 1         # ^ means power; <= also works
        hits += 1
    end                     # closes the if
end                         # closes the for
  • function count_in_disk(n) … end defines the function; return hits returns the count.
  • 1:n includes both endpoints; _ is an unused loop variable.
  • Indent for readability; use end to close each block.

▶ Script: cell “2. Reading the loop”. Julia ^ corresponds to Python **. The input n is a positive integer. Ranges need not start at 1: 3:5 contains 3, 4, 5. The 1-based indexing convention concerns arrays, not all ranges; see the reference table.

Julia syntax reference

Variables and types

x = 3            # Int64
y = 2.5          # Float64
name = "Ada"     # String
typeof(x)        # Int64

Assign with =. A type declaration is not required.

Numbers and Unicode

10 / 4      # 2.5
2^10        # 1024
-7 ÷ 2      # -3: truncate toward zero
fld(-7, 2)  # -4: floor division, as Python -7 // 2
α = 0.1     # type \alpha then TAB
3 ≤ 4       # type \le then TAB; <= also works
2π          # 2 * π

Strings

name = "Ada"
a, b = 3, 4
"Hello, $name"          # "Hello, Ada"
"$a + $b = $(a + b)"    # "3 + 4 = 7"
"foo" * "bar"           # "foobar"
'a'                     # a Char

Use $name or $(expression) to insert a value into a string. * concatenates strings; single quotes denote one character.

Arrays, ranges and matrices

v = [10, 20, 30, 40, 50]
v[1], v[end]          # 10, 50
v[2:4]                # [20, 30, 40]; Python v[1:4]
3:5                   # 3, 4, 5
collect(1:2:9)        # [1, 3, 5, 7, 9]
[i^2 for i in 1:5]    # [1, 4, 9, 16, 25]
M = [1 2 3; 4 5 6]    # 2×3 matrix
M[2, 3]               # 6

Standard arrays start at 1. Ranges include their endpoint when reached by the step. Dense matrices use column-major storage; NumPy’s default is row-major.

Tuples and dictionaries

t = (1, "two", 3.0)
p, q, s = t                   # q == "two"
nt = (x = 10, y = 20)
nt.x                          # 10
d = Dict("apple" => 3, "pear" => 5)
d["apple"]                    # 3
haskey(d, "pear")              # true

Conditionals

x = 11
if x ≥ 16
    "excellent"
elseif x ≥ 10
    "pass"
else
    "fail"
end
x ≥ 0 ? "non-negative" : "negative"

Julia elseif corresponds to Python elif.

Loops

words = ["a", "b"]
for (i, w) in enumerate(words)
    println(i, " ", w)
end
[(i, w) for (i, w) in enumerate(words)]
# [(1, "a"), (2, "b")]

enumerate counts from 1.

Local scope: let … end

v = [10, 20, 30, 40, 50]
let
    acc = zero(eltype(v))     # zero with v's element type
    for i in eachindex(v)     # valid indices
        acc += v[i]
    end
    acc                      # the value of the block
end

acc stays local to the block. Later demonstrations time code inside let.

Functions and keyword arguments

square(x) = x^2                         # one-line definition
cube = x -> x^3                         # anonymous function
greet(who; punct = "!") = "Hi $who$punct"
greet("Bob"; punct = "?")               # "Hi Bob?"

The last expression is returned if return is omitted. Keyword arguments follow ;.

Broadcasting and mutation

xs = [1.0, 4.0, 9.0]
square(x) = x^2
square.(xs)           # [1.0, 16.0, 81.0]
@. xs^2 + 1           # add a dot to each operation
xs .= sqrt.(xs)       # update xs rather than create a new array
sort!(xs)             # modify xs (the ! naming convention)

Chained dotted operations fuse into one loop. Broadcasting also works with functions you define.

Structs define data types

struct Point
    x::Float64
    y::Float64
end
mutable struct Counter
    n::Int
end
pt = Point(1.0, 2.0)
c = Counter(0); c.n += 1

struct fields are immutable unless declared mutable. Functions define behavior separately; see the dispatch module.
